# 苹果发布会自动日历

`simple_calendar` 的“自动同步苹果发布会”开关会把苹果正式公布的发布会加入现有月历。与游戏发布会使用同一套持久化检查机制，苹果开关和状态文件独立，个人日程、节假日及游戏类别保持各自设置。

## 来源与范围

每次从 [Apple Events](https://www.apple.com/apple-events/) 重新发现官方“添加到日历”的 ICS 地址，不固定某一年的资产路径或发布日期。接收 Apple Event 与明确的 WWDC keynote 日程，排除历史页面日期、播后回顾、ASL 重播、开发者课程、整场 WWDC 大会日期和商品预购日期。官网未提供正式日程时不推算日期。

ICS 的 UID 决定活动身份，SEQUENCE 和带时区的 LAST-MODIFIED 用于处理修订；资源地址变更不会重复添加，同一个入口的新 UID 则保留为另一场活动。Apple 当前文件的浮动 DTSTAMP 不作为公告更新时间。明确取消的活动退出正常日历；日期确定而时刻未定时标注“时间待定”，浮动的具体时刻不猜测时区。

活动时间保存为 UTC，并按设备时区放入对应的日、月。来源公告日期保留原时区语义，不使用网页发布日期当作活动日期。

## 检查与缓存

- `showAppleEvents` 默认 `false`，在目标日历实例启用；不依赖 `showGameEvents`。
- 源正常每三小时检查一次，尝试前原子保存下次检查时间。失败、重复 DATA 刷新和进程重启都服从这个间隔；调度排队和退避可能延迟实际检查。
- 启用时 DATA 周期规范为每小时；已有更快、能整除一小时的周期保留。
- 访问失败、官方页面暂时没有日历链接或已知未来日程超过核验周期时，保留已知日程并标注“待核验”。页面上消失不等于取消。
- 轮播、主题重绘和设置页只读缓存，不访问苹果网站、不写状态。
- 苹果来源只允许 `apple.com` 与 `www.apple.com` 的 HTTPS 地址，跳转也要通过校验。每轮一个入口、最多四个日历链接；沿用 4 MiB 响应、90 秒网络期限和 2 MiB 状态上限。

状态位置：

```text
$INKYPI_DATA_DIR/plugins/simple_calendar/apple_events/state.json
```

默认数据根目录为 `/var/lib/inkypi/data`。游戏状态仍在 `game_events/state.json`，回滚旧版本不需要让旧游戏解析器读取苹果数据。

## 验证范围

自动测试覆盖动态 URL、UID 去重及新活动、时区跨日跨月、日期待定、修订回退、取消、独立开关和存储、重启后的三小时间隔、失败后恢复，以及个人日程和游戏活动共存。真实渲染、主题展示与设置页的缓存读取也有集成测试。网站结构变化可能需要维护解析器。
