# October 2026 display refinements

This release keeps saved plugin settings and playback cadence unchanged.

- Bay Commute combines closure information, source and locality marks, nearby road stills, and the existing tide forecast. Camera matching requires valid coordinates, the same route, a compatible direction and a distance at most 2 km. A nearby image is labelled with its retrieval time; a missing match uses a labelled illustration. Optional camera requests have a bounded deadline and reuse the traffic-camera cache.
- APOD, the Orbital Signal launch column and the Planet Now space card use NASA digital typography roles: Inter for headings, Public Sans for labels and DM Mono for technical values. Chinese uses the existing UI font, with shared measurement and baselines. Public Sans and DM Mono assets retain their OFL licences and source manifests.
- Planet Now retains up to three actual NASA rover photographs with per-image metadata. Normal device refreshes select a photograph without increasing the hardware refresh rate. The browser adds a slow pan and a 0.9-second crossfade every ten seconds. A locally cached animation package must match the static frame's RGB hash. Missing, damaged, expired, transformed or non-native frames retain the static image. Hidden pages pause, and reduced-motion preferences disable animation.
- Steam friend activity uses a circular portrait opening into a game-cover strip with a square right edge. The in-game portrait has no green rim; its game icon has a green border and its game name is white. Three primary online portraits share a row with a compact horizontal group. `N more…` counts people not actually represented by a visible portrait.
- Money Radar uses compact issuer-logo and ticker combinations, with readable mixed-script headlines and aligned update times. Ticker compartment colours preserve brand identity. Trend colours describe numerical direction for the stated period, not whether a macroeconomic move is beneficial.
- Sports Dashboard uses game and event typography only in the esports sidebar. Chinese and unsupported characters retain the original UI face. Optional proprietary font files are installed separately into durable device data; they are excluded from source archives and Git. See the esports font source notes under the plugin's assets directory.

The release toolkit records source, configuration, readiness, terminal refresh jobs and hardware-write evidence under a project-local ignored `outputs/` round. Local screenshots or browser tests alone are not evidence that the e-paper device displayed a change.
