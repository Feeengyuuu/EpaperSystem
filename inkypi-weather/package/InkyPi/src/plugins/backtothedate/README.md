# BacktotheDate

BacktotheDate fetches one random poster image from `https://chineseposters.net/`
each time the plugin is displayed in a playlist.

By default (Auto) each poster is shown with what is known about it, the
poster as large as the page allows and the details squeezed round it:

- From the poster's page: its English and Chinese titles, pinyin, designer,
  date, publisher, size, call number, collection, theme and tags.
- From the designer's page: their years and birthplace.
- From Chinese Wikipedia: a short account of the poster's theme and the
  article's photo, which fills spare room in the details column (another
  banked poster fills it when there is no photo).

One poster takes the left with the details at the right, or the top with a
strip below when that makes it larger; three portrait posters share one shelf
with a caption each. The other fit modes show the posters bare: `Rotate
portrait posters`, `Show full poster on plain background`, or `Fill screen by
cropping` only if edge cropping is acceptable.

Source and copyright guidance are provided by Chineseposters.net:
https://chineseposters.net/about/faqs. Wikipedia text and photos are under
their own licences (CC BY-SA for the text).
