Read-only vehicle status through the private Epaper Vehicle Bridge. Schema v3 uses Tesla's read-only vehicle_location permission to show the vehicle's address and map. This plugin never wakes the vehicle or sends commands. While the vehicle is asleep, it shows the last known location for up to 24 hours instead of waking it.
Store it in API Keys as EPAPER_VEHICLE_BRIDGE_TOKEN. The token is never saved in playlist settings or the plugin cache.
Store the Google Maps Platform key in API Keys as GOOGLE_MAPS_API_KEY. It is used for the Vehicle Status address and map and is never saved in playlist settings or the plugin cache.
900 seconds avoids duplicate API reads during previews. The recommended playlist interval is 3 hours.
