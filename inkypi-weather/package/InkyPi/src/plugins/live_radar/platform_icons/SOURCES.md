# LiveRadar platform icon sources

The bundled icons are unmodified official site/brand artwork normalized onto a
64x64 transparent canvas. Normalization only applies proportional Lanczos
resizing and transparent padding; it does not recolor, redraw, or remove a
background. The runtime pastes each asset directly without a badge border or
fill.
