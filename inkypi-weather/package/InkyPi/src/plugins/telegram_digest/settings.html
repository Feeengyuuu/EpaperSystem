Account mode reads an authorized local Telethon session file. Displayed account messages are remembered as read only inside this plugin; Telegram global read state is unchanged. Bot mode only reads bot updates. Ad rules drop promotions, invite links and link spam in channels and groups (never private chats). With AI ranking, the text of every unread message the scan reads, private chats included, is sent to OpenAI to rank it and write a headline; each message is ranked once and the page falls back to the rules when the daily limit is reached.
